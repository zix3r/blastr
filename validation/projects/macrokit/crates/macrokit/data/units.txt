# Unit table for macrokit.
#
# Columns, separated by `|`:
#   symbol | dimension | scale | offset
#
# The canonical value of a unit is `value * scale + offset`, expressed in the
# base units of its dimension. Dimensions are written as space separated
# `CODE<exponent>` tokens; codes are, in the order used by `[i8; 7]`:
#   LEN MASS TIME CURR TEMP AMT LUM
# An omitted exponent means 1, an empty dimension means "dimensionless".
#
# The file is sorted by symbol; `build.rs` sorts again and rejects duplicates,
# so the generated table is stable across machines.
