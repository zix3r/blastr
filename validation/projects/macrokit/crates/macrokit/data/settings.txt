# Baseline setting definitions for macrokit's generated schema.
#
# Columns, separated by `|`:
#   key | kind | default | required | aliases | deprecated | doc
#
# `kind` is one of:
#   bool
#   int:<min>..<max>
#   float:<min>..<max>
#   text:<max-len>
#   quantity:<dimension>;<min>..<max>
#
# Quantity bounds are expressed in the canonical (base SI) unit of the
# dimension. `aliases` is a comma separated list and may be empty. Defaults are
# validated by `build.rs` against the unit table, which keeps the two generated
# tables consistent.
